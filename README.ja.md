# ksjdata

[![R-CMD-check](https://github.com/UchidaMizuki/ksjdata/actions/workflows/R-CMD-check.yaml/badge.svg)](https://github.com/UchidaMizuki/ksjdata/actions/workflows/R-CMD-check.yaml)

[English](https://uchidamizuki.github.io/ksjdata/README.md) \| 日本語

ksjdata
は、国土交通省が公開している国土数値情報（KSJ）を提供するパッケージです。

- `ksj_available`
  はカタログです。対応しているすべてのファイルを、データセット、年、地域、データセットのページとともに一覧にします。これを絞り込んでファイルを選びます。
- [`ksj_get()`](https://uchidamizuki.github.io/ksjdata/reference/ksj_get.md)
  は、1 つのファイルをダウンロードして読み込み、1 つのレイヤーを `sf`
  tibble
  として返します。複数のファイルは、[`purrr::map()`](https://purrr.tidyverse.org/reference/map.html)
  などでファイル名ごとに取得します。各ファイルは
  [tarchives](https://github.com/UchidaMizuki/tarchives)
  パッケージでキャッシュされるため、ダウンロードは 1 回だけです。
- 列名は、公式の属性情報一覧に基づき日本語でつけます。古い年のデータなど、ファイルの列名（通常は
  `N03_001` のような属性コード）のまま使う場合は `col_names = "raw"`
  を指定します。

## インストール

開発版は GitHub からインストールできます。

``` r

# install.packages("pak")
pak::pak("UchidaMizuki/ksjdata")
```

## 使い方

`ksj_available` を絞り込んでファイルを探します。各行が 1
つのファイルで、`file_name`（国土数値情報のダウンロードサイトでのファイル名）で識別します。

``` r

library(ksjdata)
library(dplyr)

files <- ksj_available |>
  filter(
    dataset_code == "N03",
    year == 2026,
    prefecture_code %in% c("13", "14")
  )
files |>
  select(dataset_name, year_name, area_name, file_name, file_size)
#> # A tibble: 2 × 5
#>   dataset_name   year_name         area_name file_name                 file_size
#>   <chr>          <chr>             <chr>     <chr>                   <fs::bytes>
#> 1 行政区域データ 2026年（令和8年） 東京      N03-20260101_13_GML.zip      11.96M
#> 2 行政区域データ 2026年（令和8年） 神奈川    N03-20260101_14_GML.zip       4.88M
```

[`ksj_get()`](https://uchidamizuki.github.io/ksjdata/reference/ksj_get.md)

複数のファイルは、ファイル名ごとに取得します。

``` r

purrr::map(files$file_name, ksj_get)
```

[targets](https://docs.ropensci.org/targets/)
のパイプラインでは、[`ksj_target()`](https://uchidamizuki.github.io/ksjdata/reference/ksj_target.md)
で 1
つのファイルを取得するターゲットを宣言します。ファイルごとに宣言するには
[`tarchetypes::tar_eval()`](https://docs.ropensci.org/tarchetypes/reference/tar_eval.html)
を使います。

``` r

tarchetypes::tar_eval(
  ksj_target(name, file_name),
  values = list(
    name = rlang::syms(stringr::str_c("n03_", files$prefecture_code)),
    file_name = files$file_name
  )
)
```

データは公開されたとおりに返します。ジオメトリと座標参照系は変更せず、コードの先頭の
0 も保ち、公開されている 0 と空欄（`NA`）は区別します。

## 利用規約

利用規約はデータセットの年（版）ごとに定められ、国土数値情報のサイトのデータセットのページ（`ksj_available`
の
`page_url`）と、そこからリンクされている各版のページに記載されています。セッションで初めてそのデータセットを取得したときに、これらのページを表示します。データを公開・加工する場合は出典を記載し、加工した場合はその旨を記載する必要があります。

- 同じデータセットでも、年や地域によって利用規約が異なる場合があります。最新版がオープンデータでも古い年のデータは商用利用できない（非商用）もの、地域ごとに独自の利用条件があるものなどがあります。利用する版の利用規約を確認してください。
- サイトの記載からファイルごとの利用規約を確実に読み取ることはできないため、このパッケージは利用規約を転記していません。
- 利用規約を守る責任は利用者にあります。このパッケージは法的な助言をするものではありません。
- このパッケージの MIT
  ライセンスはコードにだけ適用され、データには適用されません。
